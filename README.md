

\# Student Management System



A console-based Student Management System developed in C++.



\## Features



\- Add new students

\- Display all students

\- Search students by faculty number

\- Delete students

\- Save student information to a file

\- Load student information from a file



\## Technologies Used



\- C++

\- Standard Template Library (STL)

\- Vectors

\- Structures

\- File Handling (`ifstream`, `ofstream`)



\## How to Run



Compile the program:



```bash

g++ main.cpp -o StudentManagementSystem

```



Run the program:



```bash

./StudentManagementSystem

```
